Can paired switches leave one lamp on?

family: invariants, reachability · status: answered · attractor: enough switch operations can produce any lighting pattern

Question

A panel has six lamps, all initially off. Each move chooses any two distinct lamps and toggles both: off becomes on and on becomes off. Can any sequence of moves leave exactly one lamp on?

Accepted routes (2)

Parity of lit count invariant under pair toggles VALID

sonnet (blind player 1) · 2026-10-05 · strategy new: parity-invariant-obstruction · depth 1 · opus/v2 / criterion v2
reason: The chain is sound and contains no simulation: it reasons from a structural invariant (lit-count parity) and never tracks the board state. It is the first accepted chain on an empty frontier, so all three of its landmarks are new: changes in steps of plus two, minus two or zero; parity is invariant; and an even start cannot reach an odd target.
CHAIN by blind player 1
1. 6️⃣💡 (root) — There are six lamps, all initially off.
2. 🔀2️⃣ (root) — Each move toggles exactly two distinct lamps, flipping each one's state.
3. ❓ (← 1, 2) — Can some sequence of moves leave exactly one lamp on (1️⃣💡 on, the other five off)?
4. 🔢 (← 2) — Each move changes the count of lit lamps by two, up or down, or leaves it the same: both lamps off go on (+2), both on go off (−2), and one of each swaps (0).
5. 🧬 (← 4) — So the parity of the lit count (even or odd) never changes, which makes it an invariant of every move.
6. 0️⃣ (← 1) — At the start no lamp is lit, so the lit count is zero, which is even.
7. 🟰 (← 5, 6) — Because parity is preserved and starts even, the lit count is even after any sequence of moves.
8. 1️⃣ (← 3) — Exactly one lamp on means a lit count of one, which is odd.
9. 💥 (← 7, 8) — The required odd count contradicts the always-even count, so the target is unreachable.
10. 👀 (← 9) — Self-check: the argument never used the number six, so it holds for any lamp count. It also never assumed the order of moves, so it covers every sequence.

LANDMARKS:
- Each move changes the number of lit lamps by plus two, minus two, or zero.
- The parity of the lit count is an invariant of every move.
- The start has an even lit count (zero), but one lit lamp is odd, a contradiction.

ANSWER: No

Graph degree view with handshake double counting VALID

sonnet (blind player 2) · 2026-10-05 · strategy new: handshake-double-counting · depth 2 · opus/v2 / criterion v2
reason: The argument is sound and does no step-by-step simulation. It reads the whole move sequence as one graph and counts all the line-ends at once, never tracking state move by move. Two of its landmarks are not in route 001's set: the reduction "lamp on ⇔ its dot has odd degree" and the double count "total line-ends is even". Route 001 instead used an invariant that holds after every move.
CHAIN by blind player 2
1. 💡 (root) — There are six lamps, all initially off.
2. 🔀 (root) — Each move picks two distinct lamps and toggles both.
3. ❓ (← 1, 2) — 6️⃣💡 all off, then paired toggles: can exactly 1️⃣ lamp end up on?
4. 🕸️ (← 2) — Draw each lamp as a dot and each move as a line joining the two chosen dots. A whole sequence of moves is then a bundle of lines, and repeated pairs are separate lines.
5. 👆 (← 2, 4) — Each line touches exactly two dots, so every move adds exactly two line-ends in all.
6. 🧮 (← 5) — The total number of line-ends over all dots is therefore even, because it is built from pairs.
7. 🔁 (← 1, 4) — A lamp starts off and flips on each touch. It is on exactly when its dot has an odd number of line-ends.
8. 🔆 (← 3, 7) — Exactly one lamp on would mean exactly one dot has an odd number of line-ends, and the other five have even numbers.
9. ➕ (← 8) — Five even counts plus one odd count give an odd total number of line-ends.
10. 👀 (← 4, 7) — Self-check: a repeated pair gives two lines on the same dots, so it adds an even count to each dot and the argument still holds.
11. 💥 (← 6, 9) — The total must be both even and odd, which is a contradiction.

LANDMARKS:
- Moves are lines between lamp-dots, and a lamp is on exactly when its dot has an odd number of lines (a graph degree view).
- Double counting: every line has two ends, so the total of line-ends is even.
- Handshake principle: the number of odd-degree dots must be even, so exactly one odd dot is impossible.
ANSWER: No

Attempts (1) — the boundary

Even-sized lit sets closed under pair-toggle combination DUPLICATE

sonnet (extender) · 2026-10-05 · strategy new: parity-invariant-as-closed-family · opus/v2 / criterion v2
reason: "Pairable" just means an even-sized set, so closure under combining is route 001's parity-of-the-lit-count invariant in set language, and the single-lamp step is route 001's odd-target obstruction. The commuting-moves landmark, where a lamp is on exactly when it was touched an odd number of times, is route 002's lamp-state-reduces-to-degree-parity view, so no landmark is new in substance.
CHAIN by extender
1. 6️⃣💡 (root) — There are six lamps, all initially off.
2. 🔀2️⃣ (root) — Each move chooses two distinct lamps and toggles both.
3. ❓ (← 1, 2) — Can some sequence of moves leave exactly one lamp on (1️⃣💡 on, the other five off)?
4. 🧩 (← 2) — A move undoes itself, and the order of moves does not matter. Each lamp's final state depends only on whether it was touched an odd or even number of times.
5. 🗂️ (← 1, 4) — Describe any state as the set of lit lamps. Making a move combines the current set with the move's pair of lamps, where a lamp in both leaves the set and a lamp in only one joins or stays.
6. 🫧 (← 4, 5) — Cancellation: when the combined set meets the new pair, every shared lamp drops out of both. So overlaps vanish rather than pile up.
7. 🏘️ (← 2, 5) — Define the family of "pairable" sets, those whose lamps can be split into twosomes with none left over. The empty set belongs to it, and every move's pair of lamps belongs to it.
8. 🤝 (← 5, 6, 7) — Closure: combining two pairable sets gives a pairable set. The shared lamps are removed from both sets, which takes away the same amount from each, and the remaining lamps still pair up.
9. 🏁 (← 1, 7, 8) — The start is the empty set, which is pairable. Each move combines the current set with a pairable pair, so every reachable state stays pairable.
10. 1️⃣ (← 3, 7) — A single lit lamp is a set that cannot be split into twosomes, because one lamp is left over. So it is not in the pairable family.
11. 💥 (← 9, 10) — The target state would have to be both pairable and not pairable, so it is unreachable.
12. 👀 (← 8) — Self-check: repeated moves and overlapping pairs are covered by the cancellation step, so the closure holds for every sequence of any length.

LANDMARKS:
- A move undoes itself and moves commute, so the final lit set is the combination of the chosen pairs with overlaps cancelling.
- The family of pairable (splittable into twosomes) lamp sets is closed under combining, and contains the start and every move.
- A single lit lamp is not pairable, so it lies outside everything reachable.

ANSWER: No
