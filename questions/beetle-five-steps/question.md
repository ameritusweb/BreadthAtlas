# Question

A beetle starts at a corner of a cube and walks along exactly five edges, moving to a new corner with
each edge. **Can it finish at its starting corner?** Answer the same question for an octahedron.

# Reference answer (referee only)

**Cube: no. Octahedron: yes.** The cube's corners can be two-coloured so every edge joins different
colours; each step switches colour, so an odd number of steps cannot return. The octahedron has
triangular faces, so no such colouring exists; around a triangle (three steps) and out-and-back along an
edge (two more) returns in five. Tolerance: both parts exact; a route must give the obstruction for the
cube and a construction for the octahedron.

# Why it is in the atlas

Two-case family: the answer flips between solids for a structural reason. Calculation route: count
closed walks; holistic route: colour the corners.
