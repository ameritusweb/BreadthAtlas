# Question

A sealed collection of boxes contains at least one counter. Each allowed move takes a counter from one box and places it into a different box in the same collection. Counters cannot be destroyed or leave the collection. Can a sequence of moves make every box empty?

# Reference answer (referee only)

No. Each transfer preserves the total number of counters, which is initially positive. An all-empty collection has none. An alternative argument follows one initial counter: every move either leaves it in its current box or places it in another box in the collection. Tolerance: exact no; local emptying is insufficient.
